Features

Finds your games
Steam, Heroic, Lutris and the app menu on Linux; Steam, Epic, GOG and Heroic on Windows. Each with its own icon.
Ports and rewrites
Spots ports, recomps and rewrites like Ship of Harkinian, Zelda 64: Recompiled and OpenMW, and Rust games you built yourself. It asks before adding them.
Your list, your way
Pin favourites to the top, rename or hide any game, add one with +. The games you play most come first.
Keyboard or controller
Ctrl+Alt+H opens the panel and typing finds a game, even with a typo. On a controller, hold Start and Select.
Light
About 35 MB of memory and no CPU use while hidden.
Nothing hidden
Open source, with no ads, accounts or tracking. It only goes online to GitHub, to check for a new version. Every download is built by GitHub straight from the public code, with a signed record you can check.
AI help prompt
The ? button copies a prompt containing the full documentation, for AI assistants that can read your computer to answer questions about Hanami.

Start

  1. Linux: download the AppImage, mark it executable and run it. Windows: run the installer; it needs no admin rights.
  2. Hanami's icon appears in the system tray. It tells you there when a new version is out.
  3. Press Ctrl+Alt+H or click the icon to open the panel. Settings are described in the guide.
